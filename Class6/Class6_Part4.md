## Real-World Case Study 1: Sales Territory Analysis

**Scenario:** Analyze sales performance across territories.
**Techniques:** Choropleth by region, bubble for stores, heat for customers.

---

## Common Mistakes to Avoid

**Top Pitfalls:**
❌ Using count instead of rate on choropleth
❌ Rainbow color schemes
❌ Ignoring projections
❌ Too many data points (slow, cluttered)
❌ Missing legends/scale bars

---

## Best Practices Checklist

**Before publishing a map:**
- [ ] Appropriate map type selected
- [ ] Data normalized (if choropleth)
- [ ] Color scheme appropriate
- [ ] Legend included and clear
- [ ] Source/attribution noted
- [ ] CRS appropriate for region
- [ ] Performance acceptable
- [ ] Tested on mobile (if web)

---

## Accessibility

**Make maps usable for everyone:**
- Use color-blind friendly palettes
- Don't rely on color alone
- Provide text alternatives
- High contrast

**Test:** colorbrewer2.org has color-blind safe options
