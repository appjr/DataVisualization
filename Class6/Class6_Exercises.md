## Exercise 1: Create a Choropleth Map

**Objective:** Visualize data across geographic regions.

**Task:**
1. Load US states shapefile
2. Join with demographic or sales data
3. Create choropleth map with appropriate colors
4. Normalize data properly (rate, not count)
5. Add legend and title

**Deliverables:**
- [ ] Choropleth map (PNG)
- [ ] Code (Python script or notebook)
- [ ] 1-paragraph interpretation

---

## Exercise 2: Interactive Point Map

**Objective:** Build interactive map with folium.

**Task:**
1. Load point data (stores, incidents, etc.)
2. Create folium map
3. Add markers with popups
4. Add marker clustering for many points
5. Export as HTML

**Deliverables:**
- [ ] Interactive HTML map
- [ ] Code
- [ ] Screenshots of key features

---

## Exercise 3: Multi-Layer Dashboard

**Objective:** Combine multiple geographic layers.

**Task:**
1. Base layer: Region boundaries (choropleth)
2. Point layer: Locations (bubble map)
3. Add basemap for context
4. Create legend for all layers
5. Make interactive with plotly

**Deliverables:**
- [ ] Multi-layer visualization
- [ ] Code with comments
- [ ] Brief write-up
